## 2. 已修正的问题

### 2.1 MATLAB 包函数名与文件名不一致

原代码中多个文件名与函数声明不一致，例如 `GroupShrink.m` 文件内声明 `group_shrink`，同时调用处混用 `Functions.GroupShrink` 和 `Functions.group_shrink`。MATLAB 包函数要求文件名、函数名、调用名一致。

处理：统一为 `Functions.groupShrink` 等 lower camelCase 名称。

### 2.2 问题类型字段不一致

`elasticProblem` 设置 `problem.type='elastic'`，而 `feasibilityNorm` 曾检查 `'Elastic'`，导致 elastic 残差无法正确记录。

处理：`objectiveValue` 与 `feasibilityNorm` 均使用 `'elastic'`。

### 2.3 GrpADMM.tv 的注释误判

原注释认为 `x` 更新是假设 `D'D=I` 的简化。对 GrpADMM Algorithm 1 来说，`x` 子问题 (7b) 使用普通拉格朗日函数 `L`，不含增广二次项，因此在 `S=I` 时确实没有 `D^TD` 项。

处理：保留公式

$$
x=(\mu c+\tau^{-1}u-D^T\lambda)/(\mu+\tau^{-1}),
$$

并修正注释。

### 2.4 GrpADMM.elastic 字段错误

`GrpADMM.elastic` 原来使用 `problem.normK2` 作为步长分母，而 elastic-net 拆分中的约束是 `x-y=0`，约束算子范数平方应为 `1`；数据拟合矩阵 `K` 的谱范数平方不应混作约束范数。

处理：`elasticProblem` 中 `normK`、`normK2` 表示数据拟合矩阵 `K` 的谱范数；另增 `constraintNorm=1`、`constraintNorm2=1`，并令 `normH2=1`。`GrpADMM.elastic` 的步长改为使用 `constraintNorm2`。

### 2.5 PADMC.tv 字段错误

`PADMC.tv` 原来用 `problem.normK2` 计算 TV 的线性化参数；TV 问题应使用 `||D||^2`。

处理：改为 `problem.normD2`，并在 `tvProblem` 中补充 `normD`、`normD2`。

### 2.6 IADMM.elastic / IADMM.tv 的步长

Xie 文献 Algorithm 2 要求 `tau in (0,1]`。原代码硬编码 `tau=0.4`，没有在文献中对应的说明。

处理：改为 `tau=1`，作为 Algorithm 2 的精确子问题特例。

### 2.7 AGrpADMM / APADMC 的不可用强凸 LAD

GrpADMM 论文 Algorithm 2 的 LAD 强凸变体对应

$$
\mu_1\|x\|_1+\mu_2\|x\|^2+\|w-c\|_1,\quad \mu_2>0.
$$

当前 `ladProblem` 默认 `mu2=0`，不是强凸 LAD。

处理：`AGrpADMM.lad` 与 `APADMC.lad` 增加 `problem.mu2>0` 检查；标准 LAD 不再静默套用加速强凸算法。

### 2.8 删除不必要的数值保护

`APADMC.lad` 中 `rx=rxBase/max(beta,eps)` 是额外数值保护。强凸前提 `mu2>0` 且 `k>=1` 时 `beta>0`。

处理：改为 `rx=rxBase/beta`，不添加文献未说明的保护策略。

## 5. 仍需注意的问题

1. `Problems.ladProblem` 依赖 CVX 求 `PhiStar`。如果本机未安装 CVX，问题生成会失败；这不是算法函数本身的问题。
2. `IADMM.lad` 的 `x` 子问题不是闭式解，而是近端梯度内循环并检查相对误差条件。若要严格复现实验，应记录内层误差是否每次满足条件。
3. `PADMC.lad`、`PADMC.tv`、`APADMC.tv` 是由通用框架移植得到，不是 PADMC 文献中的数值实验对象。
4. `GrpADMM.elastic`、`AGrpADMM.elastic` 是通用框架移植到当前 elastic 拆分模型，不是 GrpADMM 文献中的原始 elastic 实验。
5. 未添加自适应步长、线搜索、残差平衡等文献未包含的数值策略。
